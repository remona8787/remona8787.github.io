## 2. 검토한 콘셉트

1. **블랙 박스 시네마** — 전체를 어두운 몰입형으로. 사진은 돋보이지만 읽기·검색 화면이 답답해지고, 브리프의
   "보라색·어두운 배경으로 과도하게 채우지 말 것"에 어긋납니다. 채택하지 않음.
2. **미디어 메시** — LED 격자를 정체성으로 삼은 데이터형 화면. 독창적이지만 기술 대시보드처럼 보일 위험이
   큽니다. 사진 없는 작품의 패턴과 홈 소개 띠의 LED 그래픽으로만 남김.
3. **화이트 큐브 / 블랙 박스(채택)** — 현대 미술관 건축의 두 공간을 교차합니다. 읽고 찾는 곳은 밝은 전시실
   (오프화이트 벽, 잉크색 글자, 가는 선), 빛 작품을 보는 곳은 어두운 미디어아트실(차콜)입니다. 바이올렛은
   상호작용에만 씁니다. 모션은 빛이 조리개를 통과하는 움직임, 사진의 노출이 맞춰지는 움직임, 파사드를
   훑는 빛으로 정했습니다.

참고한 원칙(복제 아님): Apple(스크롤에 묶인 전환), MoMA(큐레이션 타이포그래피와 색인), Google Arts &
Culture(사진 중심 탐색), Behance(옆으로 넘기는 시각 갤러리), 인터랙티브 스튜디오 사이트(공간감 있는 무대).

## 3. 디자인 시스템

### 색
- 밝은 전시실: 배경 `#F6F5F2`, 표면 `#FFFFFF`, 패널 `#ECEBE6`, 선 `#DEDCD4`, 글자 `#151A38`(브랜드 잉크),
  보조 `#55576A`.
- 블랙 박스: `#0E0F14` / `#16171F`, 글자 `#F4F2EC`, 보조 `#B9B7C4`. 두 테마 모두에서 고정이며
  `.box` 클래스가 다크 토큰을 국소 적용합니다.
- 강조: 바이올렛 `#6B52DE`(다크 `#A08CFF`)는 선택 상태·포커스·검색 버튼·진행선에만 씁니다.
  버밀리언은 '진행 중'과 저장 하트에만 씁니다.
- 모든 글자/배경 조합은 `tests/contrast.test.cjs`가 WCAG 4.5:1(비텍스트 3:1)로 검사합니다(149개 통과).

### 글자
- Pretendard Variable. 한글 라벨에는 자간을 쓰지 않고, 라틴 대문자 라벨만 `.tracked`를 씁니다.
- 단어 단위 줄바꿈 `word-break:keep-all`. 한 단어가 칸보다 넓을 때만 `overflow-wrap`이 최후 수단으로
  줄을 바꿉니다. 제목은 `text-wrap:balance`, 본문은 `pretty`를 씁니다.
- 크기(320→1920px 유동):

  | 등급 | 크기 | 굵기 |
  |---|---|---|
  | Display(무대 제목) | 42→100px | 800 |
  | H1 | 32→56 | 800 |
  | H2(섹션) | 26→44 | 800 |
  | H3(카드) | 17/19 | 700 |
  | 본문 | 16px | — |
  | 캡션 | 13px | — |
  | 최소 | 12px | — |

- 사진 출처는 11px 알약입니다. '© 작가'는 좁으면 줄여 쓰고, 라이선스 코드는 절대 끊지 않습니다.

### 간격·그리드·모서리
- 4px 단위입니다. 섹션 간격은 `clamp(64px, 6vw+44px, 136px)`, 여백은 `clamp(16px, 4vw+4px, 64px)`,
  최대 폭은 1400px입니다.
- 홈 대표작은 12열 비대칭 배치입니다(7열 대표작 + 5열 두 점). 모바일은 2열 지그재그로 오른쪽 열이 48px
  내려갑니다.
- 모서리: 사진 4px(인화지), 조작 요소 12px, 칩·주요 버튼은 알약형입니다. 그림자는 떠 있는 것(탭바, 시트,
  메뉴)에만 씁니다.

### 내비게이션
- 휴대폰: 56px 상단바와 화면 가장자리에서 떨어진 불투명 유리 탭바(5개)를 씁니다. 홈에서는 상단바가 무대
  위에 투명하게 놓였다가 스크롤하면 어두운 유리가 됩니다.
- 태블릿: 80px 아이콘 레일.
- 데스크톱: 64px 상단바 아래에 7개 섹션 띠가 있습니다. 현재 섹션은 바이올렛 밑줄로 표시합니다.

### 모션(13장)
섹션마다 다른 움직임을 씁니다.

| 대상 | 움직임 |
|---|---|
| 무대 | 제목 단어가 마스크에서 올라옴, 사진이 천천히 밀려 들어옴(6.5초마다 교차), 파사드를 훑는 빛, 사진별 진행선, 일시정지 버튼, 스와이프 |
| 섹션 제목 | 스크롤에 맞춰 단어별로 올라옴 |
| 주제 색인 | 각 행 위로 잉크선이 그려짐 |
| 대표작 | 조리개처럼 열리며 사진이 자리를 잡음 |
| 블랙 박스 띠 | 방이 열리듯 넓어짐 |
| 지역 | 각 권역의 빛이 켜짐 |
| 옆으로 넘기는 갤러리 | 사진이 틀 안에서 패닝 |
| 데스크톱 세계 갤러리 | 가운데 열이 반대로 흐름 |
| 상세 | 사실 표의 선이 그려지고, 읽기 진행선 표시 |

원칙은 다음과 같습니다.
- 스크롤 연동 효과는 요소가 화면에 다 들어오면 끝납니다.
- 내용에는 이동·클립만 쓰고 투명도는 쓰지 않습니다. 그래서 스크린숏과 접근성 검사는 언제나 최종 색을 봅니다.
- 링크가 있는 요소는 확대·축소하지 않습니다. 터치 영역 크기를 지키기 위해서입니다.
- 움직임 줄이기 설정이면 모두 끕니다. 무대도 자동으로 넘어가지 않습니다.
- 변형 금지(ND) 라이선스 사진은 움직이지 않습니다.
- 라이브러리 없이 CSS `animation-timeline`을 쓰고, 지원하지 않는 브라우저에서는 정지 상태로 보입니다.

## 4. 바뀌지 않은 것
데이터·ID·상세 링크, 지역 분류, 검색·필터, 지도와 좌표, 저장·코스·기록, 언어 전환, 연구 데이터·내보내기,
사진 출처·라이선스 정책(`art-photo-policy.js`), 계정 로직, 수집·배포 자동화, 관리자 화면은 그대로입니다.
홈 순서만 국내 우선으로 바꿨습니다: 무대 → 주제 색인 → 국내 미디어파사드 → 국내 미디어아트·전시(블랙 박스)
→ 지역 → 세계 → 읽을거리 → 답사 코스 → 소개.
