# Image Rights Workflow

`data/image_rights_matrix_50.csv`는 장소 단위 획득전략이다.
**아직 특정 이미지 50장이 사용허가 완료되었다는 뜻은 아니다.**

## Asset-level 승인 조건
각 이미지마다 최소:
- source_url
- original_file_url
- creator
- copyright_holder
- license_code
- license_url 또는 KOGL 유형
- commercial_use_allowed
- derivatives_allowed
- attribution_text
- checked_at
- clearance_status

## 앱 렌더 조건
`clearance_status = cleared`만 노출.

## 작품 사진 주의
건물/장소 사진을 쓸 권리와, 사진 속 미디어아트 작품 자체의 저작권은 별개일 수 있다.
작품 클로즈업/스크린샷은 운영사·작가·제작사의 권리 조건을 추가 확인한다.
