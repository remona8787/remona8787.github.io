# 이미지 등급 (v2.0)

대표 이미지 판정(`site-public-cleared/art-photo-policy.js`)은 사이트와 수집기가 함께 씁니다. v2.0부터 한 가지 화질 기준 대신
쓰임새별 등급을 둡니다. **저작권·출처와 작품 일치 기준은 모든 등급에서 같고, 등급은 크기와 화질만 다룹니다.**

| 등급 | 쓰는 곳 | 조건 |
|---|---|---|
| A 프리미엄 | 홈 메인 배너, 홈의 큰 추천 칸 | 권리·작품 일치 + 원본 폭 1,600px 이상 + (측정했다면) 선명도 25 이상, 압축 블록 30 이하 |
| B 일반 | 목록·검색·지역 카드, 상세 페이지 대표 사진, 작품 사진 갤러리 | 권리·작품 일치 + 원본 폭 640px 이상 + (측정했다면) 선명도 25 이상, 압축 블록 60 이하 |
| C 맥락 | 건물 외관, 도시·주변, 설치 장소, 행사 장소, B에 못 미치는 작품 사진 | 권리 확인. 작품 사진과 나눠 "맥락 사진"으로 표시하고 대표 이미지 실적에 넣지 않음 |

- 대표 이미지 확보 = 그 사례에 A 또는 B 사진이 하나 이상 있음. 확보율 = 확보 사례 수 ÷ 공개 사례 수.
- 상세 페이지는 960px보다 작은 원본을 늘리지 않고 원래 크기로, 여백을 두고 보여 줍니다(기존 동작).
- 예전 단일 기준(폭 900px, 선명도 25, 압축 블록 30)을 통과한 사진은 모두 B 이상입니다(회귀 테스트
  `tests/art-search.test.mjs`). 예전 기준 때문에 대표 이미지에서 빠지는 사진은 없습니다.
- 홈 배너 사진 4장은 모두 A입니다(2026-11-13 데이터).

## 편집자 등급

편집자가 사진을 카드 크기와 원본 크기로 직접 본 뒤 `approve_image` 결정에 등급·종류·초점을 남길 수 있습니다.

```json
{"action":"approve_image","target":"<ID>","image":"<Commons 파일 이름>","grade":"B","kind":"project_media",
 "focal":{"x":0.5,"y":0.1},"note":"본 내용","by":"…","at":"…"}
```

- `grade` A·B·C: 측정값 대신 편집자의 판정을 씁니다. 원본 폭 하한(A 1,600px, B 640px)은 넘을 수 없습니다. C는 맥락 사진으로 둡니다.
- `kind` project_media·project_installation·architecture_context: 사진이 보여 주는 것. 작품 종류를 주면 그 사진은 편집자 검토로
  작품에 연결되고(`identity: commons_editorial_review`), 맥락 종류를 주면 맥락 사진이 됩니다.
- `focal`: 카드에서 잘릴 때 남길 위치(0~1).
- 권리는 바꾸지 못합니다. 라이선스가 맞지 않거나 작품 일치를 증명하지 못한 사진은 등급을 줘도 대표 이미지가 되지 않습니다.

## 기준을 정한 근거 (2026-11-13 표본)

측정 렌디션(960px)을 카드 크기와 1:1로 잘라 직접 비교했습니다.

| 표본 | 압축 블록 | 선명도 | 본 결과 |
|---|---|---|---|
| 현재 대표 사진 (Lublin 버섯 조명, Casa Europea) | 29, 28 | 71, 66 | 기준 이하, 깨끗함 |
| Fibonacci-Reihe (운나) 두 장 | 34 | 70, 71 | 위 표본과 구분되지 않음 |
| Lichtskulptur Gelmeroda (필름 스캔) | 36 | 61 | 필름 입자가 점수를 올림, 블록 없음 |
| 국립현대미술관 복도 | 50 | 70 | 블록 보이지 않음 |
| Lichtzeitpegel (도해가 그려진 사진) | 54 | 60 | 글자 경계와 매끈한 하늘이 점수를 올림 |
| 1989 (로테르담, 어두운 밤) | 72 | 52 | 카드 크기에서는 네온 숫자가 분명하지만 원본 크기에서 어두운 부분 잡음이 큼 |
| 일본 풍선 설치 두 장 | 17, 63 | 17, 23 | 흐림. 선명도 기준이 맞게 거름 |
| 롯데월드타워 소등 | 82 | 92 | 매끈한 하늘의 계조. 화질이 아니라 피사체(조명이 꺼진 탑) 문제 |

압축 블록 점수는 어두운 잡음, 필름 입자, 매끈한 하늘, 글자에도 올라가 50대까지는 눈에 보이는 손상이 없었습니다. 그래서 B는 60까지
받고, 흐림은 선명도로 거릅니다(A와 같은 25). 60을 넘는 사진은 편집자가 보고 등급을 줄 때만 B가 됩니다.
