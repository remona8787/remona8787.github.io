운영자 정보가 아직 등록되지 않았습니다.

궁금한 점이나 바로잡을 정보가 있으면 알려주세요. 자주 묻는 내용은 아래에 정리했어요.

회원가입이 필요한가요?

아니요. 지금은 계정·로그인 기능이 없어요. 저장한 장소, 코스, 메모는 이 기기의 브라우저에만 저장되고 운영자에게 전송되지 않아요.

기록을 다른 기기로 옮기기

기존 기기의 설정에서 JSON 백업을 내려받고, 새 기기나 새 주소에서 같은 화면의 ‘백업 복원’으로 불러오세요. 브라우저와 도메인이 다르면 기기 저장소(localStorage)는 자동으로 공유되지 않아요. 브라우저의 사이트 데이터를 지우면 기록도 지워지니 백업해 두세요.

사진이 보이지 않을 때

사진은 촬영자와 라이선스를 확인한 뒤에만 보여드려요. 확인 전이거나 조건에 맞지 않으면 ‘사진 준비 중’ 그래픽이 표시돼요. 사진을 불러오지 못하면 상세 화면의 출처 링크에서 원본을 확인하세요.

정보 오류·권리 침해 신고

프로젝트 화면의 ‘정보 오류 신고’·‘이 사진 신고’에서 GitHub 이슈(공개) 또는 이메일 중 하나를 고를 수 있어요. 아래 이메일로 직접 보내도 돼요. 권리 침해 신고는 확인하는 동안 해당 사진을 우선 내리고, 결과를 회신해요. 처리 절차는 이용 안내에 있어요.
