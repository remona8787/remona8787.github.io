개인정보 처리방침

운영자 정보가 아직 등록되지 않았습니다. 이 상태로는 공개 출시용 처리방침이 완성되지 않습니다.

(이하 “운영자”)는 「개인정보 보호법」에 따라 빛의 건축(이하 “서비스”) 이용자의 개인정보를 다음과 같이 처리합니다.

1. 처리하는 개인정보와 목적

  • 회원가입 없이 이용: 저장 장소, 방문 기록, 메모, 코스, 설정은 이용자 기기(브라우저·앱 저장소)에만 보관되며 운영자 서버로 전송되지 않습니다.
  • 계정 이용 시(선택): 이메일 주소, 비밀번호(암호화 저장, 인증 서비스가 처리), 로그인 세션 — 계정 식별·로그인·기기 간 동기화 목적. 이용자가 작성한 저장 장소·방문 기록·메모·코스·설정 — 기기 간 동기화 목적.
  • 방문 사진(선택): 로그인 후 이용자가 첨부한 사진. 업로드 전 기기에서 JPEG로 다시 저장해 원본의 EXIF·GPS 메타데이터를 제거하고 긴 변을 최대 2,048px로 줄입니다. 사진 화면 자체에 담긴 위치·인물 정보는 제거되지 않으니 유의하세요. 비공개 저장소에 보관되고 본인만 60초 유효 링크로 열람합니다.
  • 연구 데이터 회원(선택, 서버가 연결된 경우에만): 필수 — 계정 이메일, 이용약관·개인정보 처리방침 동의 버전과 시각. 선택 — 표시 이름, 소속기관, 이용자 유형, 연구 분야, 데이터 이용 목적, 국가(이용 통계와 데이터 이용 조건 안내 목적이며, 입력하지 않아도 다운로드할 수 있습니다). 다운로드 이력 — 데이터셋·버전·형식·시각·성공 여부(남용 방지를 위한 시간당 한도와 이용 통계 목적). 이력은 공개 데이터나 공개 저장소에 포함하지 않습니다.
  • 오류 신고(선택): 신고 사유와 내용, 답변을 원할 때 적는 이메일, 로그인 상태라면 계정 ID — 사진·정보 오류를 검토하고 바로잡기 위한 목적. 신고는 운영자와 편집자만 열람합니다.
  • 위치 정보: “주변 검색”을 요청할 때만 기기 위치 권한을 사용하며, 좌표를 서버에 저장하지 않습니다.
  • 자동 수집: 서비스 접속 시 호스팅·인증 서비스가 IP 주소, 접속 시각, 브라우저 정보 등 접속 기록을 보안·장애 대응 목적으로 처리할 수 있습니다. 서비스는 광고·분석용 추적 도구를 사용하지 않습니다.

2. 보유 및 파기

  • 계정 정보와 동기화 기록, 방문 사진: 회원 탈퇴(계정 삭제) 시 지체 없이 삭제합니다. 계정 삭제는 [계정과 동기화 → 계정 관리]에서 재인증 후 요청합니다.
  • 연구 데이터 회원 정보: 회원 탈퇴 시 지체 없이 삭제합니다. 다운로드 이력은 탈퇴 시 계정과의 연결을 지워 개인을 알아볼 수 없는 이용 통계로만 남깁니다.
  • 오류 신고에 적은 이메일: 신고 처리가 끝나면 즉시 삭제합니다. 신고 내용은 데이터 정정 기록으로 보관하며, 로그인 상태로 신고한 경우 탈퇴 시 계정과의 연결을 지웁니다.
  • 서비스 제공자의 데이터베이스 백업에 남은 사본은 해당 백업의 보관 주기가 지나면 자동 삭제됩니다.
  • 기기 내 기록은 [데이터 및 설정 → 기록 초기화]로 이용자가 직접 삭제합니다. 내려받은 백업 파일과 다른 기기의 사본은 이용자가 별도로 삭제해야 합니다.
  • 관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 분리 보관 후 파기합니다.

3. 처리 위탁 및 외부 서비스

  • Supabase Inc. — 회원 인증, 데이터베이스, 사진·연구 데이터 파일 저장, 오류 신고 보관(저장 위치: 대한민국 서울 리전). 계정을 만들거나 신고를 남긴 경우에만 해당합니다.
  • 웹 호스팅 제공자 — 서비스 파일 전송 및 접속 기록 처리.
  • 장소 사진·정보와 전국·세계 장소 목록 동기화: 서비스를 열면 최대 6시간에 한 번 이용자 기기에서 Wikidata와 Wikimedia Commons에 장소 정보와 고정된 장소 목록 조회를 요청하고, 화면에 보이는 장소 사진의 권리 정보를 Commons에서 확인하며, 사진은 Wikimedia 서버에서 직접 불러옵니다. 요청에는 이용자의 개인정보나 기록이 포함되지 않지만, 각 제공자가 IP 주소 등 접속 정보를 처리할 수 있습니다.
  • 다음 서비스는 이용자가 해당 기능을 사용할 때 요청됩니다: Wikidata(세계 검색), OpenStreetMap(지도 표시).

운영자는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 법령에 근거한 요청이 있는 경우는 예외로 합니다.

4. 이용자의 권리

이용자는 언제든지 자신의 개인정보 열람·정정·삭제·처리정지를 요구할 수 있습니다. 앱의 계정 화면에서 직접 확인·삭제하거나, 아래 연락처로 요청하면 지체 없이 조치합니다. 만 14세 미만 아동은 계정을 만들 수 없습니다.

5. 안전성 확보 조치

전송 구간 암호화(HTTPS), 데이터베이스 행 단위 접근 제한(본인 기록만 조회·수정), 비밀번호 비저장(인증 서비스의 해시 처리), 관리 권한 최소화, 사진 비공개 저장 및 단기 열람 링크를 적용합니다.
