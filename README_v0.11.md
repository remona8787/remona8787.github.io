# 빛의 건축 v0.11 — Fieldwork workspace

최신 사용자 앱은 `site-public-cleared/`입니다. v0.10의 Supabase SQL·수집 코드와 원본 데이터는 보존했습니다. 기존 `prototype/` 및 과거 README는 역사적 자료이며 최신 실행 대상이 아닙니다.

## 이번에 구현한 것
- 데스크톱 사이드바 / 모바일 하단 탐색, 장소 상세 직접 링크
- 장소명·지역·카테고리·무료·실내 필터, 전체 목록 페이지 확장
- 저장 장소와 실제 저장 가능한 Wikidata 후보
- 개인 코스 생성·이름/날짜/메모 편집·순서 변경·삭제·복제
- 원본 6개 큐레이션 복사, 저장 장소로 코스 만들기
- 현장 기록 작성·수정·삭제: 날짜·평가·메모
- JSON 백업·형식 검증 후 복원, CSV, ICS 종일 일정, 인쇄/PDF
- 데이터 검토 목록, 확인일 경과·프로그램 종료 판정
- 요청 시 Commons 사진 조회, 저장한 좌표 보유 세계 후보 지도
- 개인 기록 로컬 저장, 이전 v0.3 저장/방문 횟수 이관, 다른 탭 변경 반영
- 오프라인 앱 셸, 설치 안내, 저장 실패·망 오류 처리
- 서버 미설정 관리자 로그인 비활성화, SDK 지연 로딩
- 6개 privileged Edge endpoint의 secret 검사 fail-closed 처리
- 일부 scaffold endpoint가 데이터 수집 성공으로 오인되지 않도록 501/실패 상태 표시

## 데이터에 대한 사실
첨부의 화면 데이터는 49곳이고 좌표는 모두 null입니다. 문서의 '50곳'을 숫자 그대로 재사용하지 않았습니다. 기존 장소·프로그램 내용은 이번 작업에서 재검증하지 않았습니다. 그래픽은 실제 장소 사진이 아닙니다. 확인일·출처를 유지하고 현재 영업 중이라고 표시하지 않습니다.

## 실행
가장 쉬운 방법은 배포된 비공개 주소를 여는 것입니다.
로컬에서는 Python 3 설치 후 프로젝트 폴더에서:

    python -m http.server 8080 --directory site-public-cleared --bind 127.0.0.1

브라우저: http://127.0.0.1:8080
Windows에서는 `START_WINDOWS.bat`도 제공합니다. HTML 파일을 file://로 직접 열면 일부 기능이 제한될 수 있습니다.

## 검증
Node 22 이상, 추가 npm 의존성 없이:

    node --test tests/*.test.cjs
    node scripts/check.mjs
    node scripts/build.mjs

테스트는 순수 로직과 VM 기반 DOM 계약 검증이며 실제 브라우저 E2E/시각 검증이 아닙니다. 실제 브라우저 제어 도구가 제공되지 않아 브라우저·모바일 레이아웃·실제 오프라인 설치 동작 검증은 수행하지 못했습니다. 외부 검색, 사진, 지도는 실제 네트워크 환경에서 별도 점검이 필요합니다.

## 저장과 복원
기록은 `aol11_workspace` 키에 저장됩니다. 첫 로드에서 이전 `aol3_saved`, `aol3_visited`를 읽어 이관합니다. 날짜가 없던 과거 방문 횟수는 날짜를 꾸며 만들지 않고 별도로 보존합니다. 코스/방문 ID가 중복되거나 날짜/장소 참조/좌표/데이터 크기가 잘못된 백업을 거부합니다. 손상된 기존 데이터가 발견되면 자동 덮어쓰기를 차단합니다.

새 도메인으로 이동하면 localStorage는 공유되지 않습니다. 이전 브라우저/도메인에서 JSON 백업 후 새 주소에서 복원하세요. JSON에 개인 메모가 포함되므로 파일 공유에 유의하세요. 세계 후보 상세 링크는 해당 후보를 보유한 기기에서만 열립니다.

## 아직 외부 연결이 필요한 부분
- Supabase 실제 프로젝트·SQL 01~16·Edge Functions 배포·관리자 계정
- 수집 작업의 실제 실행 및 SQL 통합 테스트
- 서버가 승격한 장소를 프런트엔드 seed와 동기화하는 발행 파이프라인
- 사진 영구 캐시/권리 관리 서버는 기존 소스에 보존; 새 사용자 화면은 Commons 요청 조회 사용
- 일반 사용자 계정과 기기 간 클라우드 동기화, 서버 저장 및 협업
- 좌표 검증/정규화 및 실제 이동경로·대중교통 소요시간
- 스토어 제출, 공개 출시용 약관·지원 채널, 도메인

운영 API 키나 service_role key를 브라우저 config에 넣으면 안 됩니다. 공개 가능한 프로젝트 URL/key만 config에 넣고 서버 secret은 서버 환경변수로 설정하세요. 서버 설정 없이 수집/승격이 실행됐다고 주장하지 않습니다.
