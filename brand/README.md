# 빛의 건축 — Aperture symbol
세로의 건축적 면과 사이의 빈 공간으로 빛의 통과를 표현합니다. 작은 다홍 면은 바닥에 닿은 빛입니다.

Deep Navy #151B3F / Midnight Indigo #25265A / Purple #7563C9 / Soft Violet #A39CE0 / Coral #ED786B / Background #F8F8FC.
Noto Sans KR, font-display swap, 셀프호스팅 WOFF2. Coral은 소량의 강조에만 사용합니다.

symbol.svg / symbol-mono.svg, 한글·영문, 가로·세로, light·dark SVG. SVG 워드마크는 텍스트 기반이며 최종 인쇄 전달 시 폰트를 설치하거나 아웃라인 처리해야 합니다. PNG 심볼 및 앱 아이콘, Android adaptive foreground가 포함됩니다.
