개인정보 안내 · Public Beta

현재 정적 Public Beta는 서버 회원가입을 사용하지 않습니다. 저장·방문 기록은 이용자의 브라우저 localStorage에만 저장됩니다.

외부 서비스

지도 표시 시 OpenStreetMap 타일을, 전세계 검색 시 Wikidata API를, 이용자가 이미지 확인을 요청할 때 Wikimedia Commons API를 호출합니다. 해당 서비스에는 일반적인 웹 요청 정보(IP 주소, 브라우저 정보 등)가 전달될 수 있으며 각 제공자의 개인정보 정책이 적용됩니다.

위치

“내 위치” 버튼을 누른 경우에만 브라우저 위치 권한을 요청합니다. 이 위치는 현재 Beta에서 서버로 저장하지 않습니다.

정식 출시 전

Supabase Auth 또는 분석 도구를 추가하면 이 문서를 실제 운영주체·문의처·보관기간과 함께 다시 갱신해야 합니다.
