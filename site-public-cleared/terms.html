이용 안내

운영자 정보가 아직 등록되지 않았습니다.

빛의 건축(이하 “서비스”)은 한국과 세계의 미디어파사드, 미디어아트, 빛 축제와 야간경관을 출처와 함께 기록하는 무료 공개 아카이브입니다. 회원가입 없이 이용하며, 저장 장소·코스·메모는 이용자 기기에만 저장됩니다.

수록 정보

장소와 프로젝트 정보는 Wikidata·Wikipedia, 공식 기관과 주최 측 누리집, 언론 보도 등 각 항목에 표시된 출처를 근거로 합니다. 출처로 확인되지 않은 내용은 추정해 채우지 않으며, 날짜가 확인되지 않은 회차는 ‘일정 확인 필요’로 표시합니다. 행사 일정, 입장료와 운영시간은 바뀔 수 있으니 방문 전 공식 안내를 확인하세요. 좌표가 확인되지 않은 장소는 지도에 핀을 표시하지 않습니다.

사진

사진은 저작자와 이용 조건(CC BY, CC BY-SA, CC0, 퍼블릭 도메인 등)이 확인된 경우에만 저작자·라이선스·원본 링크와 함께 표시하고, 원본 서버(Wikimedia 등)에서 직접 불러옵니다. 이용 조건을 확인할 수 없는 사진은 게시하지 않고 디자인된 ‘사진 준비 중’ 그래픽을 보여줍니다. 표시된 사진은 촬영 당시 모습이며, 사진의 권리는 각 원본의 라이선스를 따릅니다. 사진을 다시 쓰려면 원본 페이지의 라이선스 조건을 따르세요.

권리 침해·오류 신고와 처리 절차

  1. 각 프로젝트 화면의 ‘정보 오류 신고’·‘이 사진 신고’ 또는 아래 이메일로 사진·정보 링크와 사유를 알려주세요. GitHub 이슈로 신고하면 내용이 공개되니 개인정보를 적지 마세요.
  2. 권리 침해 신고는 운영자가 확인하는 동안 해당 사진을 우선 비공개로 돌리고, 다음 데이터 배포에 반영합니다.
  3. 확인 결과(삭제·정정·유지와 그 이유)를 신고한 방법으로 회신합니다.
  4. 삭제·정정 내역은 개인정보를 빼고 공개 저장소의 편집 기록으로 남습니다.

인용과 재사용

프로젝트를 인용할 때는 상세 화면의 ‘인용하기’ 문구(예: 빛의 건축 아카이브, 「작품명」, 기록 주소 (접속일))를 사용하세요. 데이터의 권리는 출처별로 다릅니다: Wikidata(CC0 1.0), Wikipedia(CC BY-SA 4.0), Wikimedia Commons(사진마다 표시된 라이선스). 각 출처의 조건을 따라 이용하세요.

책임과 변경

서비스는 무료로 제공되며, 수록 정보의 정확성·최신성을 보장하지 않습니다. 정보 오류로 인한 손해에 대해 운영자는 고의 또는 중대한 과실이 없는 한 책임을 지지 않습니다. 운영자는 사전 고지 후 서비스 내용을 변경하거나 중단할 수 있습니다. 외부 링크의 서비스는 각 제공자의 정책을 따릅니다. 개인 메모와 백업에 타인의 개인정보를 불필요하게 포함하지 마세요.
