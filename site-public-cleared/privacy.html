개인정보 처리방침

운영자 정보가 아직 등록되지 않았습니다. 이 상태로는 공개 출시용 처리방침이 완성되지 않습니다.

(이하 “운영자”)는 「개인정보 보호법」에 따라 빛의 건축(이하 “서비스”) 이용자의 개인정보를 다음과 같이 처리합니다.

현재 서비스는 회원가입·로그인 없이 쓰는 공개 웹 아카이브로 운영됩니다. 운영자는 회원 계정, 서버 동기화, 방문 사진 업로드, 연구 데이터 회원 기능을 제공하지 않으며, 이용자의 개인정보를 저장하는 서버를 운영하지 않습니다. 이 기능들을 도입할 때는 이 방침을 먼저 개정해 시행 7일 전부터 알립니다.

1. 처리하는 정보와 목적

  • 기기에만 저장되는 기록: 저장한 장소, 방문 기록, 메모, 코스, 설정은 이용자 기기의 브라우저 저장소(localStorage)에만 보관되며 운영자에게 전송되지 않습니다. 운영자는 이 기록을 볼 수 없습니다.
  • 위치 정보: 지도에서 “내 주변 찾기”를 누를 때만 브라우저의 위치 권한을 요청하고, 받은 좌표는 기기 안에서 가까운 장소를 계산하는 데만 씁니다. 좌표를 전송하거나 저장하지 않습니다.
  • 오류·권리 침해 신고(선택): 신고 화면은 두 가지 방법을 엽니다. ① GitHub 이슈: 이용자가 자신의 GitHub 계정으로 공개 저장소(remona8787/remona8787.github.io)에 이슈를 올리는 방식이며, 올린 내용과 GitHub 사용자 이름은 누구나 볼 수 있게 공개됩니다. 개인정보를 적지 마세요. ② 이메일: 이용자의 메일 앱으로 아래 연락처에 보내는 방식이며, 운영자는 보낸 이메일 주소와 내용을 신고 처리와 회신 목적으로만 씁니다.
  • 접속 기록: 서비스 파일을 전송하는 호스팅 제공자(GitHub Pages)가 IP 주소, 접속 시각, 브라우저 정보 등 접속 기록을 보안·장애 대응 목적으로 처리할 수 있습니다. 운영자는 이 기록을 따로 수집하지 않습니다.
  • 서비스는 광고·분석용 추적 도구와 쿠키를 사용하지 않습니다.

2. 보유 및 파기

  • 기기 내 기록은 이용자가 [설정 → 기록 초기화]로 직접 삭제하거나 브라우저의 사이트 데이터 삭제로 지울 수 있습니다. 내려받은 JSON 백업 파일과 다른 기기의 사본은 이용자가 별도로 삭제해야 합니다.
  • 이메일 신고: 처리와 회신이 끝나면 신고 내용 중 데이터 정정에 필요한 사실(장소·사진·사유)만 정정 기록으로 남기고, 이메일 주소는 정정 기록에 넣지 않습니다. 받은 메일은 처리 후 1년 안에 삭제합니다.
  • GitHub 이슈: 이용자가 직접 올린 공개 글이므로 이용자가 GitHub에서 수정·삭제할 수 있습니다. 운영자에게 요청하면 운영자 권한으로 이슈를 삭제합니다.
  • 관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 분리 보관 후 파기합니다.

3. 외부 서비스

운영자는 개인정보 처리를 위탁하지 않습니다. 서비스를 쓰는 동안 이용자의 브라우저가 다음 서비스에 직접 요청하며, 각 제공자가 자신의 정책에 따라 IP 주소 등 접속 정보를 처리할 수 있습니다. 요청에는 이용자의 기록이나 연락처가 포함되지 않습니다.

  • GitHub Pages(GitHub, Inc.) — 서비스 파일과 공개 데이터 전송. 신고용 이슈 페이지(github.com).
  • Wikimedia Commons·Wikidata(Wikimedia Foundation) — 장소 사진(upload.wikimedia.org)과 사진 권리 정보, 장소 정보 조회.
  • OpenStreetMap — 지도를 열 때 지도 타일.
  • 공식 출처 링크와 외부 사이트는 이용자가 누를 때만 열리며, 각 사이트의 정책을 따릅니다.

운영자는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 법령에 근거한 요청이 있는 경우는 예외로 합니다.

4. 이용자의 권리

이용자는 운영자가 처리하는 자신의 개인정보(이메일 신고)에 대해 언제든지 열람·정정·삭제·처리정지를 요구할 수 있으며, 아래 연락처로 요청하면 지체 없이 조치합니다. 기기에만 저장된 기록은 운영자가 볼 수 없으므로 이용자가 직접 관리합니다.

5. 안전성 확보 조치

전송 구간 암호화(HTTPS), 콘텐츠 보안 정책(CSP)으로 허용된 출처 외의 스크립트 차단, 공개 사이트에 비밀키·관리자 데이터를 두지 않는 배포 검사, 저장소 쓰기 권한 최소화를 적용합니다.

7. 변경

이 방침이 변경되면 시행 7일 전부터 서비스 화면에 알립니다. 다만 이번 개정처럼 처리하는 정보가 줄어드는 변경은 공개 즉시 시행합니다.
