개발 진행 현황

마지막 갱신 2026-10-20 21:00 (KST) · 배포 버전 v0.17 작업 중 (화면 재설계 진행본)

「빛의 건축」을 전 세계 미디어파사드·미디어아트 아카이브로 정식 런칭하기 위한 작업이 진행 중입니다. 이 페이지와 사이트는 작업 단계가 끝날 때마다 새로 배포됩니다. 배포 전에 매번 빌드와 오류 점검을 거칩니다.

지금 하고 있는 일

  • 실제 데이터 수집 테스트: GitHub Actions 서버에서 Wikidata·Wikimedia Commons·위키백과(13개 언어)를 실제로 수집하고 있습니다. 결과가 나오면 아래 '데이터 수집 현황'에 실제 건수를 적습니다.
  • 수집 파이프라인 마무리: 6시간마다 자동 수집 → 중복 통합 → 출처·링크 검증 → 이미지 권리·야간·미디어 판별 → 사이트 자동 배포 → 실제 공개 주소를 브라우저로 검증. 이 전체 과정을 자동화하고 있습니다.
  • 사용자 화면 재설계: 박물관형 홈, 지역·유형·테마별 탐색, 수천 건에서도 빠른 검색과 핀 묶음 지도, 사진이 중심인 상세 페이지. 내부 검수 문구는 모두 없앱니다.
  • 관리자 데이터 품질 페이지: 전체·신규 건수, 수집원별 상태, 실패 원인, 이미지 누락·링크 오류, 중복 의심, 승인 대기를 보여 줍니다. 승인·숨김·병합은 GitHub 로그인을 거쳐야 반영됩니다.

끝난 일

  • 전수 진단 보고서: 문제 25건, 화면 결함 19건 확인
  • 아카이브 데이터베이스 설계와 권한 분리(관리자·편집자·연구자), 테스트 통과
  • 뉴스·RSS·검색 기반 후보 수집기와 14개 언어 분류기. 웹에서 찾은 정보는 승인 후에만 공개됩니다.
  • 관리자 검수 콘솔(Supabase 연결 시 사용)
  • 통합 v0.17.0: 단위 테스트 450개와 브라우저 테스트 211개 통과, 수집부터 화면 표시까지 이어지는 통합 테스트 추가
  • GitHub Pages 배포 준비: 페이지 내 보안 정책(CSP), 공개 주소 설정
  • 실제 데이터 규모 조사: Wikidata에 '미디어파사드'로 분류된 항목은 0건이었습니다. 위키백과 13개 언어 검색으로 미디어파사드 건물 104곳을 확인했습니다. 라이트 설치작품 138건, 빛 축제 수십 건도 확인했습니다.
  • 원본 소스를 GitHub에 보관(source 브랜치)
