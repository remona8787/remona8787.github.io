# Privacy & Permissions — v0.1 Draft Inventory

이 파일은 앱스토어/개인정보 처리방침 작성을 위한 제품 데이터 인벤토리다. 법률 자문 문서는 아니다.

## v0.1에서 수집 예정
### 계정
- 이메일: 로그인/계정 식별
- 닉네임: 프로필 표시
- 프로필 이미지: 선택 사항

### 사용자가 직접 생성하는 데이터
- 저장한 장소
- 방문한 장소 / 방문 횟수
- 선택적으로 별점·한줄평
- 컬렉션

## 위치
권장 MVP: **정밀 위치를 서버에 저장하지 않음.**
- ‘내 주변’ 사용 시 기기 위치를 일시적으로 이용할 수 있으나 사용자 프로필에 저장하지 않는 구조를 우선.
- 위치 권한을 거부해도 주소·지역 검색으로 앱 사용 가능하도록 설계.

## 수집하지 않는 것을 권장
- 연락처
- 광고 ID
- 백그라운드 위치
- 마이크
- 카메라 (사용자 업로드 기능을 열기 전)
- 건강/금융/민감정보

## 이미지
운영자가 큐레이션한 장소 사진만 v0.1에 사용.
권리 확인 전 외부 이미지를 Storage에 업로드하지 않는다.

## 삭제
계정 삭제 기능을 출시 전 반드시 제공:
1. saved_places
2. visited_places
3. collections
4. public.users
5. auth.users
순으로 cascade/관리자 액션 검증.

## 출시 전 확정해야 할 것
- 운영 주체명
- 문의 이메일
- 개인정보 처리방침 URL
- 보관기간
- 해외 이전 여부
- 분석/Crash 도구 사용 여부
