## 브라우저 검증 제한
Sites의 managed 환경 지침상 control-browser 스킬이 없는 경우 임의의 Playwright/브라우저 대체 경로를 실행할 수 없습니다. 이 세션에는 해당 스킬이 없습니다. VM 테스트는 실제 브라우저 검증과 다릅니다. QA 시나리오 파일은 별도 제공하며 아직 실행하지 않았습니다.

## 동기화 정책
비회원 데이터는 aol11_workspace, 로그인 계정은 aol12_user_<uid>로 분리합니다. 로그인 자체는 이관 동의가 아닙니다. 비회원 기록 이관 버튼에서 명시적 동의를 받습니다. 서버 문서는 revision CAS로 갱신합니다. 다른 기기 변경과 로컬 미전송 변경이 충돌하면 자동 덮어쓰기 대신 사용자가 서버 또는 로컬을 선택합니다. 서버 기록 선택 전 현재 로컬 기록을 백업합니다. 네트워크 오류는 최대 5분 간격으로 재시도합니다. Realtime 구독과 외부 정기 수집은 별도입니다.

운영 전 필수: 실제 RLS 침투·계정 전환 중 요청 경합·2개 기기 오프라인 충돌·회원탈퇴·복구 링크·브라우저 세션 테스트. 이것들이 통과하기 전 운영 데이터 입력을 권장하는 출시 선언을 하지 않습니다.
