계정 및 데이터 삭제

운영자 정보가 아직 등록되지 않았습니다.

현재 서비스에는 회원 계정이 없습니다. 운영자 서버에 저장되는 이용자 기록이 없으므로 삭제할 계정도 없습니다. 저장한 장소·방문 기록·메모·코스·설정은 이용자 기기의 브라우저 저장소에만 있습니다.

기기에 저장된 기록 지우기

  1. 서비스의 설정에서 ‘기록 초기화’를 선택합니다. 이 작업은 되돌릴 수 없으니 필요하면 먼저 ‘JSON 백업’을 내려받으세요.
  2. 또는 브라우저 설정에서 이 사이트의 데이터(사이트 데이터·저장소)를 삭제합니다.
  3. 직접 내려받은 백업 파일과 다른 기기의 기록은 각각 삭제해야 합니다.

신고·문의 기록 삭제

이메일로 보낸 신고나 문의의 삭제를 원하면 같은 이메일 주소에서 아래 연락처로 요청하세요. 확인 후 지체 없이 삭제하고 결과를 회신합니다. GitHub 이슈로 남긴 신고는 GitHub에서 직접 수정·삭제하거나 운영자에게 삭제를 요청할 수 있습니다.

계정 기능을 도입하면 이 페이지에 계정 삭제 방법을 먼저 안내합니다.
