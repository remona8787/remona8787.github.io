# 빛의 건축 v0.6 — Image Review Mode

두 빌드를 제공합니다.

## site/ — INTERNAL REVIEW
- Commons 후보 이미지를 일단 최대한 보여줌
- 라이선스 자동 판정 미완료 이미지는 `권리확인 필요`
- creator / license / source 링크는 계속 표시
- MY에서 이미지 권리검토 CSV 다운로드
- 시각검토/콘텐츠 선별용

## site-public-cleared/ — PUBLIC
- 자동 판정상 cleared 이미지에 한해 표시
- pending 이미지는 placeholder 유지
- 실제 공개 배포용

출처 표기만으로 사용권이 생기는 것은 아니므로,
내부 검토 빌드와 공개 빌드를 분리했습니다.
